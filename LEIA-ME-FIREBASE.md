# AnalitCalc — Firebase

O AnalitCalc utiliza Firebase Authentication para contas e Cloud Firestore para perfis e catálogo de ferramentas.

Para cadastrar a primeira ferramenta (`titulometria-classica`) e a permissão por usuário, veja [GUIA-ANALITCALC-FIREBASE.md](./GUIA-ANALITCALC-FIREBASE.md).

**Não cadastre `apps/analitcalc`:** AnalitCalc é a plataforma; cada documento de `apps` representa uma ferramenta independente.
